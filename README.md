## 🌟 Executive Overview

This web platform bridges **cognitive learning psychology** with **conversion rate optimization (CRO)** and precision test preparation. Designed as an institutional-grade portfolio, it helps international professionals, university aspirants, and test-takers identify their exact English bottlenecks across:

* **CELPIP Preparation:** Canadian PR, immigration, and citizenship score acceleration.
* **Duolingo English Test (DET):** Algorithm-aware adaptive strategy drills and score prediction.
* **Corporate English & Executive Presence:** High-stakes boardroom communication, presentations, and cross-functional negotiation.

## ✨ Key Features & UX Design

- **🏛️ Top Fold Accreditation Rail:** Instant institutional authority featuring official marks for Cambridge Assessment English, Duolingo Global Partner Network, IH Budapest, and CXL Certified Optimizer.
- **💬 100% Verified Preply Reviews:** Unedited feedback from real students with real-time category filtering (`All`, `CELPIP Prep`, `Duolingo DET`, `Business English`, `Strategy & Fluency`) and direct link to Shradha's verified Preply profile.
- **🔐 The Credential Vault:** Interactive audit gallery featuring verified certifications (including the official CELPIP Level 2 certificate) with high-resolution lightbox modal inspection.
- **🎯 Multi-Step Smart Diagnostic Intake Form:** Interactive, progressive-disclosure assessment that isolates learner roadblocks and routes to tailored booking strategies.
- **☀️ Light Mode by Default:** Premium editorial aesthetic featuring an off-white paper canvas, deep obsidian typography, and subtle sage accent tones with an optional dark mode toggle.
- **⚡ Performance & Motion:** Ultra-smooth micro-interactions powered by Framer Motion, accessible screen-reader compliance, and Turbopack fast refreshes.

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v18.17 or later) installed.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/pepsilonyt/shradhalearningstrategist.working.git
   cd shradhalearningstrategist.working
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3001](http://localhost:3001) in your browser to view the application.

### Available Scripts

- `npm run dev` — Launches the Turbopack local development server on port 3001.
- `npm run build` — Compiles an optimized static production bundle.
- `npm run start` — Starts the production Next.js server.
- `npm run lint` — Runs ESLint for code style validation.
